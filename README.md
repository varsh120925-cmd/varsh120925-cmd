### 04. RE-DACT – AI-Based Document Redaction System

**Domain:** Artificial Intelligence | NLP | Data Privacy | Cybersecurity

🔗 [View Repository](https://github.com/varsh120925-cmd/RE-DACT)

**Overview**

RE-DACT is an AI-based document redaction application designed to identify and hide sensitive Personally Identifiable Information (PII) from documents.

It helps protect confidential information by detecting sensitive data before documents are shared.

**Key Features**

- **Sensitive Data Detection:** Identifies information such as Aadhaar numbers, PAN numbers, phone numbers and email addresses.
- **Named Entity Recognition:** Uses spaCy to identify relevant personal information in text.
- **Regex-Based Detection:** Uses regular expressions to detect structured sensitive information.
- **Document Processing:** Supports text, PDF and image-based document workflows.
- **Automatic Redaction:** Hides detected sensitive information.
- **User Authentication:** Includes login functionality with password hashing.
- **Audit Logging:** Maintains blockchain-style audit records of redaction activities.
- **Dashboard:** Provides a centralized interface to manage redaction operations.

**Technologies:** Python, Flask, spaCy, Regex, PyMuPDF, Pillow, SQLAlchemy, Bcrypt.

**Project Goal:** To improve document privacy and reduce manual effort in identifying confidential information.
